# SplitCodePro
Умный разделитель основных файлов с кодами на части. Есть функция самотеста, работает справка. Адаптировано для работы на телефоне. Есть возможность при разделении на части писать комментарии (автоматически). Возможность выбора папки сохранения частей. По умолчанию присылает имена 01...итд для правильной сортировки. Проверяет на потерю кода. идея мне пришла в голову работая с кодом на телефоне. как правило код получается достаточно приличным по объему и когда копируешь код....он копируется частично...думаю такие инструменты есть..но я решил это сделать сам...прогнав несколько вариантов могу сказать, что это работает и очень меня выручает. Действительно не разделяет внутри функции он просматривает...умно парсит и где можно добавляет комментарии при том когда делит на части. Очень удобная штука. Единственное, что пока что не починил нормально не видно в предварительном просмотре...вернее видно но из-за шрифта слишком крупно..когда появится возможность поправлю это при возможности
