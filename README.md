# SplitCodePro
Умный разделитель основных файлов с кодами на части. Есть функция самотеста, работает справка. Адаптировано для работы на телефоне. Есть возможность при разделении на части писать комментарии (автоматически). Возможность выбора папки сохранения частей. По умолчанию присылает имена 01...итд для правильной сортировки. Проверяет на потерю кода
